**Major changes since v0.5.45**

- Added **Campaign**, bringing World Map, Scenarios and Storyline together. Shops and Neutral Encounters now sit under Scenarios, with full-list views still available. Cutscenes moved into Storyline.
- Added **World Map editing** using the game’s artwork, including creating and editing map locations, choosing location icons, and creating and reshaping connecting roads.
- Added **Storyline tools** for viewing story flow, editing branch conditions and location unlocks, and navigating event rows and cutscenes. Existing game branches are now visible.
- Added configurable **1–18 repeated strikes**, with spell and Pedra effects showing each strike and damage synchronized to impacts.
- Added **Unique Name assignments for classes**, separate from class names, supporting existing names, new names and random naming.
- Added **Names and Text** in Tools for centralized editing of character, class, item, attack, location and other names, plus descriptions. Random-name lists support **up to 1,024 names each**.
- Added **deletion of custom content**, including classes, items, attacks, weapon types, class families, shops and encounter pools.
- Reworked **Save Editor Army Management** with live editing, character cards for stats and equipment, clearer Legion organization, reserve-based squad creation and icon-based inventory selection.
- Added automatic random names for newly created characters, with manual editing and rerolling.
- Added a **ROM build progress window** with live reports.
- Fixed export failures involving packaged C sources and combinations of High Attack, edited attacks, expanded armies, custom encounters and imported cutscenes. Added stronger checks against conflicting ROM changes.
- **General UI fixes**, including animation playback, navigation, tab styling and formation dragging.
