**Lordly Caliber v0.5.55**
Major changes since v0.5.5:

- Reworked **Storyline events** into readable WHEN / IF / THEN / ELSE logic, with Arrival, Mission and Area Investigation views and an optional raw instruction view.
- Added **event creation and logic-tree editing**, including AND / OR / NOT conditions, cutscenes, recruitment, flag changes and other supported actions.
- Added **named custom story flags**, with up to 512 additional flags, in-game save support and creation directly from the event editor.
- Added scenario-specific flag descriptions, named cutscenes and links from flag conditions to the events that set or clear them.
- Added direct editing of existing **location entry conditions** and branch destinations.
- Expanded **World Map artwork editing** with background PNG export/import, editable and custom location icons, and location descriptions shared with Names and Text.
- Improved road shaping and overlapping dots. Fixed roads becoming uneditable after repeated drags, and corrected added/removed connections and unlocking in both normal gameplay and mission testing.
- Added **custom combat leader-affinity groups**, editable member classes, leader assignments and strengths.
- Integrated more recovered game C and moved consumable-effect exports to C while preserving older edited settings.
- Added Windows product, description and version information to the editor executables.
- **UI fixes**, including the encounter persuasion table layout.
