**Lordly Caliber v0.5.70 • Patch notes**

**Story cutscenes**

- Place actors, set their walking paths, attach dialogue to speakers, and write replies under each player choice. Both routes in *The Last Ferry*, built entirely in the editor, played through in Project64.
- Dialogue shows which game entry supplied the line. Gift previews follow the event’s item selection, including the Pedra of Bane. Hugo’s Report uses artwork and fonts from the loaded ROM.

**Campaign logic**

- Triggers and rules appear in game order, with each answer beside its outcome. In Project64, Zemio played a custom scene on visit one and Hugo’s briefing on visit two. Both edited Wentinus answers led to their intended battlefields.
- If your project inserted a story condition with an older editor build, re-export it to pick up the branch fix.

**Consumables, shops & combat**

- Assign a consumable’s effect and animation together or change either independently. Heal Leaf restored the advertised HP in both the Army and battlefield menus.
- Shop previews account for date-based prices, Goth and stack limits. Repeated-strike previews let you jump to each hit and see which formation slot it reached.

**Projects & agents**

- **Load project file** sits beside **Load ROM**. The CLI and desktop share named JSON files, editable patch source and the changelog. Folders and `.lcproject` archives still work.
- The Windows ZIP includes the agent CLI. Copy its path from **Tools → Agents** and ask your local agent to run it with `--guide`. Give it your ROM and project paths when you’re ready to edit. Try “Raise Knight and Berserker base STR by 10, save a new JSON, and check both values in the exported ROM.”
- Agents can also use the editor’s controls, search matching C, inspect assembly and assets from your ROM, and build custom C or assembly patches for behavior the GUI doesn’t expose. Reopen the project to review the agent’s edits in the changelog or inspect and disable a patch under **Project code patches**.
