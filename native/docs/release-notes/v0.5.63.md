**Lordly Caliber v0.5.63 — Sound, Movement & Transformation Update**

• **Attack sound editing, down to individual parts.** Replace a whole opening/impact or just one layer. Copy sounds or parts from other attacks, import WAVs, mute and retime parts independently. The donor browser shows every sound and its parts, with individual playback before copying.

• **Previews run the original N64 sound sequencer.** We traced the audio commands and built ROM sample decoding into the editor. The desktop mix omits N64 reverb and approximates filtering/panning. Native pitch, envelopes and overlapping voices are preserved, and animation and sound play together.

• **Create new movement types.** Add them directly from Classes or manage them in Tools → Movement Types. Supports up to 254 types with editable base speed, terrain costs, passability, flying/immobile behavior and mixed-squad priority.

• **Fixed transformation requirements targeting the wrong system.** Golems, automatic evolutions and Angel Knights use different checks from the Change Class menu. Manual class changes and automatic transformations now have separate requirement controls.

• **Fixed renamed attacks keeping their old battle banner.** Combat draws separate name artwork, so changing the menu text alone left the old name visible. Added Art and Animation → Attack names, linked from Attacks, with painting and PNG import/export. Automatic lettering uses the original battle artwork to preserve the game’s style.

• Reworked body and equipment handling around complete functions adapted from matching C, replacing ten older partial code patches.

• Expanded automated testing across all 740 retail sound requests, movement rules, independent sound edits and project/ROM round trips.
