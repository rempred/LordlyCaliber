**Lordly Caliber v0.5.67 — Patch Notes**

• **Fixed exported ROM audio timing.** Music could speed up, slow down or fall out of sync—even without custom sound edits. Corrected the attack-sound hook so it preserves the game’s audio scheduling interval.

• **Fixed units getting stranded at resized map edges.** Resizing could remove the terrain buffer around the cursor boundary and leave reachable destinations marked as impassable. Export now preserves that buffer and correctly updates pathfinding along the edge.

• **Fixed in-game cursor limits for edited map boundaries.** The editor now applies a game-code patch to exported ROMs for maps whose boundaries have been edited. The cursor and movement destination consistently use the actual terrain position, preventing hills and camera angles from allowing orders outside those limits.

• **Made map boundaries clearer in the editor.** Gold dashed lines show the cursor limits, while a blue outline shows the terrain edge, making the safety margin visible when resizing maps.

• **Expanded automated game testing.** Added reusable battery-save setups for battles, town events and movement, plus audio timing checks. Added in-game checks for ground and flying squads reaching and leaving narrowed map edges across all three camera settings. Automated save loading now waits for the game’s menu state and isolates test inputs for more reliable runs.
