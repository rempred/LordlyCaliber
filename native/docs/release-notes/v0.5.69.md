**Lordly Caliber v0.5.69 — Patch Notes**

• **Fixed Chaos Frame flickering during and after missions.** The game alternates between two drawing buffers. Our counter patch assumed the Army screen’s header geometry always sat a fixed distance from its drawing commands. Mission activity could rearrange that data, causing one buffer to fail the check and the entire panel to disappear on alternating frames. CF score changes coincided with this, but the faulty check happened before the score was read. Reloading could hide the problem by rebuilding the buffers. The patch now follows the actual header pointer and correctly draws the panel in both buffers.

• **Faster repeat ROM builds.** Exports now automatically reuse unchanged compiled game code. Local benchmarks dropped from roughly 33 seconds to 18–19 seconds for repeat builds and small edits. The build report shows how much compilation was reused.

• **Reworked ROM export coordination.** Export steps now declare their dependencies and ownership of code and data. Checks cover overlapping writes, shared function replacements, class-table updates, and patch removal/restoration. Conflict errors identify the involved features and affected ROM region.

• **Fixed custom movement conflicting with other edits.** Movement initialization now patches only the relevant section of mission setup, preserving encounter reward changes, consumable artwork loading, and other scenario setup behavior.
