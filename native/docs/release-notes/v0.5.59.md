**Lordly Caliber v0.5.59**

• **New Campaign:** Start a new storyline while optionally keeping the world map, locations, roads, battlefield maps and towns. Create starting armies and select them directly or through dialogue choices.

• **Create scenarios:** Add up to 64 missions with independent completion progress. Copy a battlefield with or without squads, or start with a blank map to paint.

• **Scenario templates:** Editable opening and victory logic for mission entry, completion, world-map return and location unlocks. Shared closing logic now shows the actual undead recovery, Zombie and Angel Knight checks.

• **Scenario flowchart:** View branches, follow flags to where they are checked or changed, and double-click steps to edit. Add conditions/actions or remove branches alongside the default compact tree.

• **Clearer event editing:** Named squad, character and shared-logic checks, grouped/searchable actions and consolidated recruitment options.

• **Consumable effect trees:** Combine healing, revival, petrification cures, fatigue recovery, level/stat changes, alignment and luck with IF/ELSE conditions and editable amounts. Drag effects between branches.

• **Consumable artwork:** Import use-animation frames from ROM, Art Library or files, with resizing, colour conversion and previews. Direct shortcuts to item-icon editing.

• **Project import:** Import a project into another ROM, with a warning about original-ROM edits the project may not contain.

• **Chaos Frame fix:** Corrected garbled numbers and incorrect title colours caused by outdated texture/palette references.

• **Capacity icon fix:** Fixed the carrying-capacity pot flickering yellow or rendering incorrectly when LCK altered the next icon’s drawing settings.

• **LCK fix:** Moved LCK below Lv at the other stats’ size, with readable digits and no class-name overlap.

• **UI fixes.**
