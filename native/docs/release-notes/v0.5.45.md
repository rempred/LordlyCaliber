Changes since [v0.5.4](https://github.com/rempred/LordlyCaliber/releases/tag/v0.5.4):

- Added **spell-array editing and creation**, allowing custom commands like Basic Magic to resolve into selected attacks.
- Added **undead slaying** with an adjustable activation chance.
- Added a **3×3 targeting pattern** around the selected unit.
- Added **One strike — hit all targets together**, applying simultaneous damage and reactions with one attack animation.
- Fixed shared melee animations to strike the **closest affected unit**.
- Fixed custom spell names displaying incorrectly during battle.
- Added **Normal / Small item-name fonts**, including two-line small names.
- Added searchable **equipment compatibility warnings** for scenario squads, training opponents and custom encounters, with direct navigation to the affected assignment.
- Separated **existing ROM warnings** from newly introduced equipment problems.
- Added separate **town Morale and Takeover penalty** controls, fixing false validation errors on retail towns.
- Integrated the completed recovered attack-effects C into previews and expanded ROM rebuilding to use all available accepted matching C.
- Migrated additional class-family, shop, settlement and Chaos-counter modifications to C.
- Accelerated GitHub builds with compiler caching and shared UI compilation.
- **UI fixes.**
