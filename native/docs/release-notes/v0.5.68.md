**Lordly Caliber v0.5.68 — Patch Notes**

• **Cutscene editor overhaul (WIP).** Browse named cutscenes by event row, arrange actors and sprites on timeline tracks, and drag them into position. Separate Place and Move tools control positioning, movement duration and completion waits. Double-click timeline steps to edit them.

• **Build cutscene logic with readable commands.** Add event triggers, animations, dialogue and branching choices. Create named story flags directly in the editor, then set, clear, toggle or wait for them to connect cutscenes with scenario events.

• **Improved animation browsing and playback.** Bank grids now include appearance thumbnails, frame counts, looping indicators and an independent animation preview. Corrected missing appearances, invisible starting frames and sprite opacity that made usable keys appear blank. The scene canvas keeps a consistent 640×480 size, with controls separated to prevent overlap.

• **Fixed NPC portrait corruption.** Adding custom classes could make town dialogue show the wrong face or a black box because NPCs and added classes shared appearance IDs. Dialogue now retains its own portrait routing while custom classes keep their artwork. Unwanted custom classes can also be removed from Portraits, with Undo support.

• **Fixed edited boundaries on the last five added missions.** Missions 128–132 could fail ROM export because the cursor patch still used the old key limit. The patch now covers every supported mission and retains compatibility with earlier exports.

• **Strengthened regression tests.** Added original-game comparisons for changed-class animation lookups, expanded shared-table and patch-ownership checks, and tested boundary edits together with added missions. These checks now cover consumers and feature combinations that separate feature tests missed.
